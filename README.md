# Tienda El Castillo — PRODUCCIÓN

Este repositorio publica la tienda oficial para clientes:

https://tiendaelcastillo.github.io/

## Regla de producción

- Este repositorio está conectado al Supabase de producción y recibe pedidos reales.
- No desarrollar funciones nuevas directamente aquí.
- No crear pedidos, depósitos, pagos ni pruebas con dinero real desde este repositorio.
- Las mejoras se preparan primero en `TiendaElCastillo/tienda-el-castillo`.
- Solo se copian aquí cambios que hayan sido revisados y probados en un entorno de pruebas independiente.
- No publicar cambios experimentales ni modificar datos reales para probar.

La rama `main` debe mantenerse estable y recibir únicamente versiones aprobadas.

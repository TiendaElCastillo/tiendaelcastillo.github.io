PUBG Mobile en Cuba por ID

Para solicitar una recarga de PUBG Mobile debes usar el Character ID de la cuenta que recibirá el producto. Esta guía explica dónde encontrarlo, qué versión revisar y cómo seguir el pedido en Tienda El Castillo.

Entrar a la tiendaConocer la tienda

Versión compatible: GLOBAL

La oferta de PUBG Mobile que aparece en el catálogo de Tienda El Castillo corresponde a la versión GLOBAL. Antes de iniciar una solicitud, comprueba que el juego y la versión de tu cuenta coincidan con el producto que aparece dentro de tu cuenta de la tienda. La disponibilidad de paquetes puede cambiar y se consulta después de iniciar sesión.

Dónde encontrar tu Character ID (UID)

  1. Abre PUBG Mobile y espera a que aparezca el lobby principal.
  2. Toca el icono de tu perfil en la esquina superior izquierda.
  3. En la pantalla del perfil, entra en Info → Basic Info (Información → Información básica).
  4. Localiza el número identificado como Character ID o UID.
  5. Utiliza el icono de copiar que aparece junto al número y pégalo en el formulario, si está disponible.

El Character ID es un número y no es lo mismo que tu apodo o nombre visible. La ubicación de los botones puede cambiar con las actualizaciones del juego. Puedes consultar también la instrucción del Centro de ayuda de PUBG Mobile.

Antes de continuar: compara el ID que pegaste con el que aparece en el perfil. No uses el nombre del jugador en lugar del número ni modifiques los dígitos.

Cómo solicitar una recarga por ID

  1. Crea una cuenta o inicia sesión en Tienda El Castillo.
  2. Abre PUBG Mobile y consulta los productos que aparecen disponibles en tu cuenta.
  3. Confirma que el producto corresponda a PUBG Mobile GLOBAL.
  4. Introduce el Character ID de la cuenta que debe recibir la recarga y revisa el resumen.
  5. Comprueba el importe y el método de pago que aparecen en el checkout antes de realizar el pago.
  6. Envía la solicitud y el comprobante cuando el método lo requiera. El pago se revisa antes de autorizar la recarga.
  7. Consulta el estado actualizado desde la sección de pedidos de tu cuenta.

Los paquetes, precios y métodos disponibles no se muestran en esta guía pública: se consultan dentro de la tienda después de iniciar sesión.

Seguridad: no compartas tu contraseña

La solicitud se realiza mediante el ID de jugador. No compartas contraseñas, códigos de verificación, acceso a redes sociales ni datos de recuperación. Si una persona o página te pide esos datos para una recarga por ID, no los entregues.

Revisa el ID y el juego antes de pagar. Si la recarga no puede completarse por una incidencia, el equipo contactará contigo para revisar el caso y gestionar la devolución correspondiente.

Preguntas frecuentes

¿Qué ID necesito para PUBG Mobile?

Necesitas el Character ID, también llamado UID. Es el número que aparece en la información básica del perfil del juego; no es tu apodo.

¿Dónde encuentro mi Character ID?

Abre el lobby, toca tu perfil, entra en Info y luego en Basic Info. Copia el Character ID con el botón que aparece junto al número.

¿Qué versión de PUBG Mobile admite Tienda El Castillo?

La oferta disponible corresponde a PUBG Mobile GLOBAL. Comprueba la versión y el producto que aparecen en tu cuenta antes de pagar.

¿Debo compartir mi contraseña para recibir UC?

No. La solicitud se realiza por el ID de jugador. No compartas contraseñas, códigos de acceso ni datos de recuperación.

¿Dónde veo los paquetes y el estado de mi pedido?

Los productos, precios y métodos disponibles se consultan después de iniciar sesión. El estado del pedido se revisa desde la sección de pedidos de tu cuenta.

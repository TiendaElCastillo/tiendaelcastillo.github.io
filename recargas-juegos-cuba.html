Recargas de juegos por ID en Cuba

En Tienda El Castillo puedes solicitar recargas para juegos compatibles utilizando el identificador de la cuenta que recibirá el producto. No necesitas compartir la contraseña del juego. Consulta qué dato corresponde a cada título, revisa la región y sigue el estado de tu pedido desde tu cuenta.

Juegos y regiones disponibles

La tienda cuenta con servicios para Free Fire LATAM, Blood Strike GLOBAL, Mobile Legends: Bang Bang GLOBAL, PUBG Mobile GLOBAL y Arena Breakout Mobile GLOBAL. La disponibilidad concreta de productos se consulta después de iniciar sesión.

Qué ID necesitas para cada juego

  • Free Fire LATAM: UID o Player ID de tu perfil. Comprueba la región de tu cuenta antes de solicitar la recarga.
  • Blood Strike GLOBAL: ID de jugador de la versión Global. No confundas Global con MENA.
  • Mobile Legends: Bang Bang GLOBAL: User ID y Zone ID. Son dos datos distintos y debes revisar ambos.
  • PUBG Mobile GLOBAL: Character ID, también llamado UID. No es tu apodo.
  • Arena Breakout Mobile GLOBAL: Player ID de la versión móvil. No utilices el identificador de Arena Breakout: Infinite para PC.

Los nombres de los menús pueden cambiar con las actualizaciones de los juegos. Copia el identificador desde el perfil correcto y compáralo antes de pagar.

Cómo funciona una solicitud

  1. Crea tu cuenta o inicia sesión en Tienda El Castillo.
  2. Selecciona el juego y confirma que la región corresponde a tu cuenta.
  3. Introduce el ID del jugador y cualquier dato adicional que el formulario solicite.
  4. Revisa el producto, el importe y los métodos de pago que aparecen antes de confirmar.
  5. Envía la solicitud y el comprobante cuando corresponda. El pago se revisa antes de autorizar la recarga.
  6. Consulta el estado actualizado desde la sección de pedidos de tu cuenta.

Pagos y precios

Los métodos que pueden aparecer incluyen transferencia en CUP, saldo móvil, USDT y saldo interno de Tienda El Castillo. Las opciones disponibles se muestran en el checkout de cada pedido. Los paquetes y precios solo se consultan después de iniciar sesión; esta guía pública no muestra ofertas ni precios.

Protege tu cuenta de juego

Para una solicitud se utilizan el ID del jugador y la región que correspondan. Mobile Legends requiere User ID y Zone ID. No compartas contraseñas, códigos de acceso ni datos de recuperación. Comprueba que los identificadores pertenecen a tu cuenta antes de enviar el pedido.

Preguntas frecuentes

¿Necesito crear una cuenta para ver los paquetes y precios?

Sí. Crea una cuenta o inicia sesión en Tienda El Castillo. Los productos, paquetes, precios y métodos disponibles se consultan dentro de la cuenta.

¿Tengo que compartir la contraseña de mi juego?

No. La tienda no necesita la contraseña del juego. Utiliza únicamente el ID de jugador y los datos adicionales que solicite el formulario.

¿Qué datos necesito para cada juego?

Depende del juego: Free Fire usa UID, Blood Strike usa el ID de la versión Global, Mobile Legends requiere User ID y Zone ID, PUBG Mobile utiliza Character ID/UID y Arena Breakout Mobile usa el Player ID de la versión móvil.

¿Qué métodos de pago puedo encontrar?

Según el producto y la disponibilidad del pedido, el checkout puede mostrar transferencia en CUP, saldo móvil, USDT o saldo interno de Tienda El Castillo. Comprueba siempre las opciones que aparecen en tu cuenta.

¿Cuándo se autoriza la recarga?

Primero se revisa el pago y después se autoriza la recarga. Puedes consultar el estado de la solicitud desde tu cuenta.

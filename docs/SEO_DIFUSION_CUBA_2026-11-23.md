# Difusión transparente de la guía de recargas por ID en Cuba

**Fecha de preparación:** 23-11-2026  
**Guía central:** https://tiendaelcastillo.github.io/recargas-juegos-cuba.html

## Objetivo
Solicitar permiso a administradores de comunidades cubanas para compartir una sola vez la guía pública de Tienda El Castillo. La guía sirve para identificar el dato correcto de cada juego, confirmar la región, evitar entregar contraseñas y entender cómo se revisa y sigue una solicitud.

## Mensaje para pedir permiso al administrador

Hola. Somos Tienda El Castillo, una tienda digital que gestiona recargas de videojuegos por ID para jugadores en Cuba.

Preparamos una guía pública con los datos que necesita cada juego (incluido User ID + Zone ID para Mobile Legends), cómo revisar la región y por qué nunca se debe compartir la contraseña. También explica que el pago se revisa antes de autorizar la recarga y cómo consultar el pedido desde la cuenta.

La guía pertenece a nuestra tienda, así que queremos ser transparentes: es un recurso útil, pero también presenta nuestro servicio. ¿Las reglas del grupo permiten compartir un único enlace de este tipo? Si no está permitido, no lo publicaremos.

Gracias por su tiempo.

## Mensaje para compartir, solo después de recibir permiso

Antes de hacer una recarga de un juego por ID desde Cuba, comprueba que estás usando la región correcta y el identificador de tu propia cuenta. No entregues contraseñas ni códigos de acceso.

En esta guía de Tienda El Castillo reunimos los datos que se necesitan para Free Fire LATAM, Blood Strike Global, Mobile Legends Global, PUBG Mobile Global y Arena Breakout Mobile Global. También explicamos cómo se revisa el pago y dónde consultar el estado del pedido.

## Reglas para no perjudicar la marca

- No enviar el mensaje promocional antes de que un administrador autorice compartirlo.
- Leer y respetar las reglas de cada grupo; un permiso en uno no vale para otro.
- No publicar repetidamente ni entrar en conversaciones ajenas para forzar ventas.
- No usar cuentas falsas, reseñas inventadas, cifras de clientes ni recomendaciones fingidas.
- No pedir pagos ni datos personales dentro del grupo.
- Si no responden o no autorizan, no publicar.
